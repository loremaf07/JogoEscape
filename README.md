JogoEscape - Escape do Cientista

Um jogo em que o objetivo é escapar de um cientista.

Criadores

- Vincenzo (Zicaro)
- Lorenzo Ferreira (LMFzin)
- Mateus Machado (MML)

Tecnologias utilizadas

- Java
- HTML
- CSS

Requisitos mínimos

- Computador com pelo menos 8 GB de RAM.
- Espera-se que uma RTX 3080 ou RX 6800 XT, combinada com um Intel Core i7-8700K ou AMD Ryzen 7 3700X, seja suficiente

Inteligências artificiais utilizadas

- ChatGPT: auxílio na criação do código.
- Gemini: criação das imagens.
- Claude: auxílio na programação.
- Grok: auxílio geral no desenvolvimento.
- GitHub Copilot: correção de pequenos erros no código.
